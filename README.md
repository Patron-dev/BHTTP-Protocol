Túnel SSH por HTTP 🔒✨

- Instalación manual
- Ligero y estable
- Ideal para VPS Ubuntu / Debian

---

 📋 Requisitos

- VPS con Ubuntu 20.04 / 22.04 o Debian 11 / 12
- Acceso root
- Puerto 80 y 443 libres para su uso

---

 🚀 Instalación

Ejecuta los siguientes comandos en tu VPS:

git clone https://github.com/Patron-dev/BHTTP-Protocol
cd BHTTP-Protocol
chmod +x bhttp.sh
./bhttp.sh
